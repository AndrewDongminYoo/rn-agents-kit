# Contributing

Thanks for your interest in improving this kit.
A quick note on how this repository works, so your effort lands where it counts.

## This repository is a distribution snapshot

The code you see here is published from a separate development repository.
Each release replaces the tracked files wholesale, so **pull requests opened against this repo cannot be merged directly** — any change committed here would be overwritten by the next release.
Please do not send code changes as PRs; use the channels below instead.

## Where to send things

- **Found a bug?** Open an [Issue](../../issues).
  Include your React Native version, the skill you ran, and what you expected versus what happened.
  Bug reports are genuinely useful — they tell us the kit is being exercised on real projects.
- **Have an idea, a question, or a suggestion?** Start a [Discussion](../../discussions).

## How accepted suggestions get in

When a suggestion or fix is accepted, it is ported into the upstream development repository and shipped in the next release.
Contributors whose input made it in are credited in that release's notes and in the changelog.
So your contribution still lands in the shipped kit — just through the release, not through a merge here.

## Scope

This kit is deliberately small and audit-first: every skill inspects and reports before anything changes, and nothing changes without your consent.
Suggestions that fit that shape are the easiest to accept.
